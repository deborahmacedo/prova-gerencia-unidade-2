
# Orientações para a prova

1. Faça o fork desse repositório e compartilhe-o com o usuário gibeonufrn

2. Responda a tarefa do SIGAA com o link do seu repositório

3. A prova contém 4 questões, independentes. Altere obrigatoriamente os arquivos indicados no enunciado de cada questão e opcionalmente, crie ou altere outros arquivos que julgar necessário.

4. Tenha a atenção para realizar os commits e push apenas no intervalo da prova. Não serão aceitos, commits realizados posteriormente.
